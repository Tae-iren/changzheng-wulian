重走长征路
校园智行挑战赛

把二万五千里压进 3.4 公里的校园路线：六个点位、五支连队、每站一题。手机碰 NFC 贴片或扫二维码即进打卡页，到站计时、答题得分，总控台的大屏上实时跑出一条条“行军轨迹”，赛后自动生成一页战报。

时间2027年1月（半天） 路线第二操场 → 第一操场 → 荣茂楼 → 清源湖 → 图书馆 → 理工楼 对象数计学院各团支部，4—5 支连队

手机屏较窄时，路线图可左右滑动查看完整六站。

赛制

一条路线，三件事：走、答、看

不比谁跑得快，比谁走得稳、答得准、配合得好。每支连队 4—8 人，全程同行，缺一人不计该站成绩。

RULE 01

六个点位，逐站打卡

瑞金出发、遵义会议、飞夺泸定桥、翻越夹金山、穿越草地、会宁会师。每站有 NFC 贴片与二维码立牌，手机碰一碰或扫一扫即进打卡页。

RULE 02

每站一题，答对得分

题目由支部内容组依据党史资料命制，三选一，答对 2 分、答错 0 分，答错可在现场讲解后重答一次。

RULE 03

先比到站，再比用时

名次依次看：到站数 → 总用时 → 正确率。全部六站完成者进入“全胜”序列，终点计时停止后当场公布。

路线

六站与现场任务

点位位置依校园实际可调，调整后只需改 data.js 里的 place 字段，二维码内容不变。

CHECK IN / 现场

扫码打卡页

手机端一屏完成：选连队、读史料、答一题、生成到站码。给值守同学报码即完成登记，全程不需要登录。

REPORT / 赛后

行军战报

赛后一页纸：冠军连队、完整名次、六站热度、平均正确率。可直接打印或存为 PDF，贴进团支部活动档案。

生成战报 →
组织

怎么报名，现场怎么跑

以团支部为单位组队，队名建议取自长征地名；每队推 1 名“连长”负责报码，1 名“政委”负责答题。

报名

向团支书登记

报：连队名 + 连长姓名 + 队员人数 + 联系方式。名额 4—5 队，先报先得；报名截止后统一发放点位地图与安全须知。

现场

四步走完一站

① 全员到齐 → ② 碰贴片或扫码 → ③ 答题 → ④ 把屏幕上的到站码报给值守。值守在总控台录入，大屏随即更新。

安全

不比速度，不抢路口

全程步行，禁止奔跑穿越车道；身体不适立即停止并联系随队负责人许彬清老师（19533434078）。

归档
