不只看展，更要动手做展

这是一座由团员自己写出来、排出来、讲出来的展馆：内容组考据史实，前端组绘制行军图，现场组用现成设备把雪山与草地的体感搬进实验室——不用开发板，一枚贴片、一台家电就能开馆。

“每一代人有每一代人的长征路。”
我们这一代的长征路，写在网页源码里，也写在一枚枚 NFC 贴片里。

九十年前，一支平均年龄不到二十岁的队伍，从赣南的稻田出发，翻过雪山、走过草地，在会宁的黄土塬上把三面红旗举到了一起。今天，我们把那段路程拆成九个节点，一个一个地做成可以点击、可以触摸、可以体验的展项。

开发的过程就是学习的过程：为一句史实翻三份档案，为一个坐标校四次投影，为一条曲线改七版参数。调试卡住的那个深夜，恰好是最接近“万水千山只等闲”的时刻。

展馆定位：面向全院师生开放的“行走的思政课堂”。所有史实数据均标注来源，示意图注明“非精确比例”，装置说明标注演示参数。

瑞金出发

1934.10
江西·瑞金于都河8.6万余人

1934年10月，中央红军主力五个军团及中央、军委机关和直属部队共8.6万余人，从江西于都出发，踏上战略转移的征途。出发前，于都百姓把门板、床板甚至寿材都送到河边，架起五座浮桥，红军昼伏夜渡，四天四夜渡过于都河。

瑞金叶坪是中华苏维埃共和国临时中央政府所在地，1931年11月7日，第一次全国苏维埃代表大会在这座谢氏宗祠里召开。

把雪山与草地搬进实验室

现场组用现成设备复原两段最难走的路：一段是零下低温与缺氧，一段是看不见底的沼泽。一台数显温湿度计、一盏智能灯泡、一圈智能灯带，就够把“冷”和“险”做成看得见的现场。

DEVICE A

雪山·寒温带

夹金山口的冷，先做成体感。保温箱里放冰袋把温度压到 2—12℃，一台数显温湿度计把“冷”读成数字，智能灯泡随温度由暖白转冷白；手机碰一下箱边的 NFC 贴片，这一段讲解自动开口。

NFC 贴片数显温湿度计智能灯泡智能插座
DEMO / 联动演示12 ℃

舱温 12℃，雾化关闭，灯带冷白——队伍还在山脚。

演示参数：箱内 12℃ → 2℃ 阶梯降温，每级停留 90 秒；湿度 45%→80%。页面滑块为互动模拟，真实读数以现场数显表为准。
DEVICE B

草地·沼泽

松潘草地的凶险在于“看着像草地”。展区地面铺一米见方的“草皮”，边缘藏一圈智能灯带，配一台投影；值守同学在手机上切换场景，踩上去的一瞬，灯带由绿转红，投影里浮出一句当年的行军日记。

智能灯带投影仪二维码地贴手机切场景
DEMO / 联动演示0

压力 0：地面看似干燥，灯带常绿，投影静默。

场景逻辑：值守手机切换“晴天 / 阴雨 / 陷落”三档，灯带与投影同步变化，页面显示当前场景与史料原文。
DEVICE C

电子路条

延伸到“重走长征路”校园智行挑战赛的打卡牌：一枚 NFC 贴片加一块二维码立牌。手机碰一碰或扫一扫就进打卡页，记录连队到站顺序与答题得分，赛后在“云端行军看板”自动汇总成战报。
